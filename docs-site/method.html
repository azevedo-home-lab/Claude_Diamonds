Claude Diamonds — method

Two diamonds, one gate

Product decisions end to end with Claude. Each diamond diverges then converges — the boundary between them is a converged artifact, the Product Spec, crossed by one deliberate human commit. This page is the visual version of the README.

The shape

Canonical diagram — this same file (docs-site/assets/diamonds.svg) is embedded by the repo README; edit it once, it changes everywhere (spec 9, D9-7).

Canvas vs ledger is a separate axis — artifact identity, not thinking direction: ideas move, merge and die on the canvas; promoted items have state and history in the ledger.

How to run it

Capture into the parking lot → frame the opportunity with evidence → design ~3 compared solutions and test the riskiest assumptions → force-rank the bets and check the stack → promote (DECIDED entry, issue, publish the spec into /plan) → develop against the published spec, judged — never against the vision.

The repo contract

Each product repo carries both diamonds, separated by a one-way publish. Full text: docs/repo-contract.md.
