Two diamonds, one gate

The foundations

Shape

Double Diamond — Design Council

Both diamonds diverge then converge; the boundary is a converged artifact. Here: the Product Spec.

 Why

Decision Stack — Eriksson

Vision → Strategy → Objectives → Opportunities → Principles. The how/why test finds the first broken link.

 Problem

Opportunity Solution Tree — Torres

Outcome → evidenced opportunities → ~3 compared solutions → assumption tests. Evidence, never invention.

 What first

Prioritization — Cutler

Force-ranked 1-N bets: value vs urgency, opportunity cost, cost of delay. Ten named traps check the rank.

 Diamond 2

Spec-driven development — WFM

Development against the published spec, with enforcement that must earn its place against a recorded failure of the bare model.

How to run it

Capture into the parking lot → frame the opportunity with evidence → design ~3 compared solutions and test the riskiest assumptions → force-rank the bets and check the stack → promote (DECIDED entry, issue, publish the spec into /plan) → develop against the published spec, judged — never against the vision.
